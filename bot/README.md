# Elysium Discord Bot

Dossier autonome du bot Discord officiel **Elysium Esport** relié au site Firebase/Firestore.

Consultez la documentation complète d'installation, de connexion Firebase et d'hébergement dans [`../docs/bot-discord.md`](../docs/bot-discord.md).

## Commandes rapides

```bash
npm install
npm start        # Démarre le bot et synchronise les commandes sur les 2 serveurs
npm run register # Force uniquement la synchronisation des commandes Slash
npm test         # Lance la suite de tests automatisés
```
